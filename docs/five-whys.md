# Five Whys (hypothesis chain only)

1. **Why might new users not return?** Their notes may not contain a next action that pulls them back.
2. **Why no next action?** The first session may show generic capture rather than a useful job.
3. **Why generic capture?** Onboarding and habitual use may be designed and measured separately.
4. **Why separately?** Growth goals may target sign-up and trial rather than repeat value.
5. **Why does that matter?** Optimising early conversion can raise refunds and cancellations while repeat use falls. The `guardrail.csv` scenario models this case synthetically.

Each link is a hypothesis. **Falsify** if users mainly need archival capture, if tasks add friction, or if first-session tasks do not predict return once acquisition mix is controlled.
