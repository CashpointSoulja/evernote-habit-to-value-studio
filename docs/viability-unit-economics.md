# Viability and unit-economics memo

**Worth production work only if** note-to-task is a real high-frequency first job (discovery), and repeat value predicts retained paying use (retrospective analysis). Neither is established.

## How to read the economics in this tool
Net revenue per eligible assigned user = (paid − refunds in a fixed mature window) ÷ every mature assigned user. Using the eligible-user denominator means a variant cannot look good by converting fewer, better users. The `guardrail.csv` scenario shows why conversion alone is insufficient: trial +6.9 pp and paid +4.1 pp, but refunded users +6.2 pp and net revenue per eligible user −XTS 0.20 (synthetic). The tool rejects it.

## Cost side (qualitative)
The journey reuses existing notes, tasks and templates. The incremental cost is sequencing, copy, instrumentation, analytics QA and the experiment's opportunity cost. No cost or ROI figures are given because they would be invented.

## What would change the call
- Repeat value lifts but net revenue is flat: still potentially valuable for retention. Extend the window before deciding.
- Gains only in one acquisition source: target that source, don't scale globally.
