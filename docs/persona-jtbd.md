# Persona and jobs to be done

These are working personas built from the brief, not from research. Validate them with the plan in discovery-validation.md.

## New note user (illustrative)
- Context: just installed a note app after a meeting-heavy week.
- Job: "When I leave a meeting, I want the things I agreed to do pulled out of my notes, so I can find and finish them later without re-reading everything."
- Success: comes back on a later day, finds an open task, and finishes it.
- Anxiety: busywork, another to-do system, upsell before value.

## Growth manager
- Job: "When an onboarding variant shows a conversion lift, I want to know whether it is real, incremental, and good for the business, so I only scale things that create durable value."
- Needs: ITT denominators, mature windows, segment views, guardrails, an exportable memo.

## Product, design, engineering
- Job: "Before we build, I want to see the exact journey and event contract, so we can estimate it and instrument it correctly."
- Needs: the session event log (same schema as the cohort CSV), the data dictionary, ADRs.
