      Baseline vs task-first: what differs

      Baseline: blank note

      • Opens straight into an empty note.
      • Tasks exist but are not suggested.
      • The revisit cue is a generic note list.

      Task-first: job-led

      • Asks for the job first, then opens a meeting note.
      • Invites picking lines to become tasks before any plan prompt.
      • The revisit cue names the open tasks and where they came from.

      Both use features Evernote already has (notes, tasks, templates). The hypothesis is only about the order of the first session. There is no claim that the current onboarding is broken.

      Metric contract (provisional hypotheses)

      • First value: a note is saved and at least one meaningful task is created in the first 24 hours. In the preview, "meaningful" means at least three words.
      • Repeat value (primary): on a later day within seven days, the user revisits and completes a task on the same day.
      • Trial and paid conversion are reported separately.
      • Net revenue per eligible user = paid minus refunds within a fixed 14-day mature window, divided by every mature assigned user. Synthetic XTS prices. This is not lifetime value.
      • Randomisation unit: user. Stable assignment: FNV-1a hash of assignment_seed|user_id mod 100 against the seed's treatment percentage. Denominator: intent-to-treat from the assignment row. Event rows are never counted as users.
      • No decision is made if any of these fail: quarantine above 5%, orphan events above 1%, a missing event type, assignment conflicts or crossover above 1%, sample-ratio mismatch (chi-square above 10.83), immature users above 25%, or fewer than 150 mature users per arm.

      Facts vs hypotheses

      • Fact (public): Bending Spoons lists Evernote as a portfolio product, acquired January 2023 (bendingspoons.com).
      • Fact (public): Evernote already offers templates and tasks (evernote.com, Evernote Help Center).
      • Fact (public): the Growth manager posting describes understanding, analysing, ideating, testing and scaling.
      • Hypothesis: a job-led note-to-task first session gives a stronger reason to come back before any plan prompt. Not shown by any data here.
      • Not claimed: that current onboarding is broken, any real uplift, or access to any Evernote or Bending Spoons data.
