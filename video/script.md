# Demo video script (source for voiceover and subtitles)

Vertical 1080×1920 recording of the live UI. The voiceover is generated text-to-speech of exactly these lines, and the subtitles are timed to the same segments.

1. **intro**: This is Habit-to-Value Studio, an independent concept by Ayo Ahmed for the Bending Spoons Growth manager role. All data is synthetic. It is not affiliated with Evernote or Bending Spoons.
2. **job**: In the task-first journey, a new user picks a job first: turn meeting notes into next actions. That opens an original synthetic meeting note.
3. **edit**: The note is editable. I change the title and save it locally. Nothing leaves the browser.
4. **tasks**: Now I tick the lines that need doing and turn them into tasks. The note stays unchanged, and each task links back to its line. First value is reached.
5. **revisit**: I schedule a revisit for day two and simulate it. No notification is sent. The cue names the open tasks. Completing one on a later day counts as repeat value. Only then does a transparent plan preview appear, and it never purchases anything.
6. **import**: Now the growth side. I import a seeded cohort CSV. Rows are validated and deduplicated, and users come only from assignment rows.
7. **contract**: The contract is pre-registered before results: user-level stable assignment, intent-to-treat, mature windows, minimum sample, and guardrails.
8. **simpson**: This cohort shows a six point lift in repeat value overall. But traffic mix differed between the ramp phases. Holding the acquisition mix fixed, the effect reverses to minus two points. So the decision is iterate, not scale.
9. **guardrail**: Next, conversion goes up, but refunds rise and repeat value falls. Net revenue per eligible user drops. The rollout is rejected.
10. **biased**: Finally, a biased, incomplete export. Refund events are missing, assignments are dropped, the sample ratio is off, and most users are immature. The tool refuses to call a winner and lists every reason.
11. **export**: Every analysis exports an evidence memo with the contract, gates, results, decision and limitations. That's Habit-to-Value Studio: a working user flow, and a disciplined scale decision.
